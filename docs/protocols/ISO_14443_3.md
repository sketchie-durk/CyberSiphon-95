# 📡 PROTOCOL SPECIFICATION: ISO/IEC 14443-3 (Anti-Collision)

## 1. Frame Format
Frames in the Anti-Collision phase are characterized by the **SENS_RES** (Sense Response).

### Bit-Level Collision Detection
The PCD detects collisions by observing if the received bit differs from the transmitted bit during the `SEL` sequence.

| Bit | Value | Meaning |
|---|---|---|
| 0 | OK | No collision |
| 1 | COLL | Collision detected; PCD must backtrack |

## 2. State Transition Matrix
`IDLE` ➔ `REQA` ➔ `ANTICOLLISION` ➔ `SELECT` ➔ `ACTIVE`

## 3. SAK (Selection Acknowledge) Analysis
The SAK byte defines the PICC's capabilities:
- **Bit 0:** ISO 14443-3 (0) vs ISO 14443-4 (1)
- **Bit 1:** Proprietary capabilities
- **Bit 2:** High-speed support
